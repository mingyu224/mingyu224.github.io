# Mingyu의 사진 갤러리

사진을 감상하고 제목순 또는 최신순으로 정렬하는 개인 웹사이트입니다.

## 기능
- 반응형 사진 갤러리
- 제목 A–Z 정렬
- 날짜 최신순 정렬
- 원본 / 흑백 보정 전환
- 기기 사진 임시 추가

## 알고리즘
두 정렬 버튼 모두 직접 구현한 병합 정렬을 사용합니다.

- 시간 복잡도: O(n log n)
- 최대 추가 공간 복잡도: O(n)
- 일반적인 버블 정렬의 평균 O(n²)와 비교하면,
  데이터가 많을 때 병합 정렬이 점근적으로 효율적입니다.
- 사진 3장 정도에서는 실제 속도 차이를 체감하기 어렵습니다.

## 실행 방법
index.html을 브라우저로 엽니다.

## 참고
추가한 사진은 서버에 저장되지 않으며 새로고침하면 사라집니다.
추가 사진의 날짜는 실제 촬영일이 아니라 파일의 마지막 수정일입니다.

## 성능 테스트

사진 제목 데이터를 생성하여 병합 정렬과 버블 정렬을 비교했다.
동일한 데이터를 제목 오름차순으로 정렬하고,
각 알고리즘을 5회 실행한 평균 시간을 측정했다.

데이터 생성과 화면 출력 시간은 제외하고,
정렬 함수 실행 시간만 performance.now()로 측정했다.

| 데이터 개수 | 병합 정렬 평균(ms) | 버블 정렬 평균(ms) |
|---|---:|---:|
| 100 | 4.560 | 42.700 |
| 1,000 | 50.140 | 2,750.080 |
| 3,000 | 185.020 | 26,945.340 |

모든 테스트에서 정렬 여부와 두 알고리즘의 결과 일치 검사를 통과했다.

병합 정렬의 시간 복잡도는 O(n log n)이고,
버블 정렬의 평균 시간 복잡도는 O(n²)이다.
측정 결과에서도 데이터가 증가할수록 버블 정렬의 실행 시간이
병합 정렬보다 훨씬 크게 증가했다.

실행 시간은 컴퓨터와 브라우저 환경에 따라 달라질 수 있다.
